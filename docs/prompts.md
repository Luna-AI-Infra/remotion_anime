# 提示词与修改意见

## 1. 启动提示词模板

> 分析我给的参考视频。先抽关键帧，按画风、配色、层次、角色动作、镜头、交互和音效节奏拆解。区分“视频中观察到的效果”和“你建议的实现方案”。先不要直接写完整动画。

> 保留纸感编辑工作台的氛围，设计自己的角色。给我三版风格稿：角色大图、一张场景效果、三个表情姿势和配色。角色要能拆成 SVG 部件。GPT 版使用绿色终端机器人；DeepSeek 版使用蓝白小鲸导演。

> 采用 React、SVG、Remotion 做 1920×1080、30fps、约30.6秒的动画。按导入、删除、转场、标题撤销、饱和度回调、卡点、导出、展示推进。角色用实体伸长手臂操作界面，手套接触目标。每帧可独立计算。先完成全片预览，再根据反馈细化。

这套方法可交给不同 Agent 使用，具体工具和模型由读者自行选择。

## 2. 实际保存的设计提示词

完整 A/B/C 英文提示词见 [design-prompts.json](prompts/design-prompts.json)。三张生成稿位于 `docs/images/`，最终选择 C。重新设计时，可搭配自己的参考图片使用，也可改成纯文字描述。

## 3. 用户对第一版的真实反馈摘录

> 手是发出的光线，我希望是手伸长去操作。
>
> 缺少动感的bgm，bgm需要和角色动作踩点然后更有节奏。
>
> 一些细节刻画还不够好。原视频调整了滤镜效果后画面也会随之变化，而且角色也有一些跳跃或者表情上的小变化，能够反映情绪的。
>
> 背景中的手机素材中的内容不够精细，可以细化一下。
>
> 特效&角色交互做的更精美一点。

对应实现：实体手臂和坐标补偿；原创120BPM配乐；共享滤镜状态；夜景、面条、猫和舞台局部动画；触碰才出现的回弹与点状反馈。

## 4. 工作台 V4 的真实修改意见

> deepseek和codex渲染的版本我希望都能够再进行一版的完善。然后deepseek使用codex的进行完善就行了。然后提示词给完善时间轴的细节。首先就是播放的时候时间轴的标线和手机画面的要同步，其次就是时间轴的片段要贴在一起。中间不要有间隙。可以用交互动画的方式让他们拼接在一起。最后除了跳舞其他的片段都缺少一些动画效果，可以适当添加一些动画效果。然后保留原始版本，继续迭代新的版本，产出高清的动画。

实现重点：累计片段起点、统一播放状态、手机局部时间与播放头绑定、加入非舞蹈片段动态。对应代码入口见 [workflow.md](workflow.md)。

## 5. 怎样提下一轮意见

用“时间点 + 看到的问题 + 想要的动作 + 验证方式”。例如：

> 在删除片段后，右边片段立即贴到前一个片段末尾。播放头进入哪个片段，手机就播放该片段相同的局部时间。不要只挪视觉位置；请增加状态检查，并给出删除前后两张预览图。
